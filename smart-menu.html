Smart Menu

Overview

The Smart Menu is a responsive web-based ordering application that enables customers to access a restaurant's digital menu using a QR code. This system is designed to handle various order modes including dine-in, takeaway, and delivery. Once scanned, the QR code leads the customer to a mobile-optimized interface where they can navigate categories, view detailed product information, apply optional customizations, and complete payment transactions. The system is tightly integrated with the back-office dashboard, POS, and kitchen displays to enable automated processing, accurate routing, and fast service turnaround.

Ordering Process Overview

Customers begin by scanning a QR code located on tables or signage. This action opens the Smart Menu in their browser. From there, they are guided through a digital menu structured into categories and subcategories. Users can explore product details including images, ingredients, and allergen information. Items can be customized with modifiers such as size, toppings, or preparation methods. Once selections are added to the cart, the user proceeds to checkout, selects a preferred payment method, and submits the order. The request is then instantly synchronized with the POS and sent to the kitchen display system for fulfillment.

Screenshots

Mobile Web App

The mobile web app is the primary interface through which customers interact with the Smart Menu system. It is fully browser-based and does not require installation. Once the QR code is scanned, users are directed to the restaurant’s customized digital menu. The interface is built with responsive web technologies, ensuring compatibility across mobile phones and tablets. The home page typically includes menu sections, language selection, and user preferences if applicable.

The product listing interface displays all items available under the selected category. Each product is shown with its name, price, visual preview, and availability status. If the product supports modifiers (e.g., size, ingredients), they can be selected prior to adding the item to the cart. Real-time synchronization with the cloud admin interface ensures that out-of-stock or disabled items do not appear to users.

Once the customer selects an item and customizes it, the system transitions to the order review screen. Here, the cart contents are listed with the option to adjust quantities, remove products, or apply promo codes. Tax and fees are also computed based on backend configurations. Upon confirming the order, the customer proceeds to the checkout phase to finalize payment using available methods configured by the business (e.g., cash, card, wallet).

After completing the transaction, a confirmation screen is shown with the order number and estimated preparation time. At this stage, the backend automatically routes the order to the POS and kitchen modules. The customer also has the option to track their order if live tracking is supported. From an administrative perspective, the transaction is logged in the reporting module for auditing and review.

Kitchen Application

The kitchen module is a browser-accessible interface that displays real-time order details for preparation staff. Orders are segmented by product and grouped based on destination (dine-in, takeaway, delivery). The interface supports station-specific routing, enabling each kitchen section to receive only the items assigned to it. Each product entry includes quantity, modifiers, and timestamps. Staff can mark items as "in progress" or "completed" and update statuses accordingly. The module also logs preparation histories for operational tracking and auditing purposes.

Smart Automation Integration

Using Smart Automation Services, orders placed via the Smart Menu are automatically pushed to the connected POS system, eliminating manual entry and reducing the potential for human error. This integration ensures that all transactions are logged, inventory is updated in real time, and reports reflect accurate data across platforms. The same mechanism handles customer screen updates, kitchen screen routing, and tax or discount application logic. The automation also simplifies refund processing and order tracking by synchronizing across modules.

Cloud Administration

The backend administration panel allows authorized users to manage and configure all aspects of the Smart Menu system. Through a web browser, users can modify product prices, descriptions, availability status, menu structures, and display orders. Each location or branch can be configured individually, while administrators can still enforce global policies. In addition to menu control, the panel supports banner and promotion setup, user account roles, and sales tracking. Permissions are role-based, with access limited based on user level (admin, branch manager, etc.).

Features

Product & Category Management

All menu items are organized into categories within the admin interface. Products can be configured with images, descriptions, prices, and optional modifiers such as size, ingredients, or preparation preferences. Categories are sortable and can be activated or deactivated based on availability. Administrators can control visibility per order type (dine-in, takeaway, etc.) and apply schedules to automate category availability (e.g., breakfast items in the morning only).

Multi-Ordering Types

The system supports multiple order modes such as dine-in, takeaway, delivery, and self-pickup. Each mode can have a dedicated menu configuration or share elements from a common global structure. This flexibility allows restaurants to optimize offerings depending on the service type. Admins can assign different pricing or availability settings for the same product based on the selected ordering type. These settings are managed centrally from the cloud admin and enforced in real time across all connected terminals.

POS & Display Integration

Every order submitted through the Smart Menu is automatically routed to the POS system, customer display, and relevant kitchen stations. This integration enables synchronized communication between front-of-house and back-of-house teams. Once an order is confirmed by the customer, all systems are updated instantly, reducing wait times and eliminating order duplication. POS receipts and tax calculations also use the same data in real time.

Data & Language Support

The Smart Menu system includes multilingual interface support (Arabic and English) to cater to a wider audience. All labels, buttons, and product names can be managed in both languages. In addition, the system generates CSV exportable data covering order history, sales figures, customer behaviors, and product popularity. Reports can be filtered by date, location, or order type and serve as a reliable source for performance reviews and forecasting.
